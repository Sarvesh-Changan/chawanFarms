# Chawan Farms UI system map

Static code map and DEV visual capture, 1 November 2026. The map distinguishes source wiring from the captured DEV rendering; the loopback-only attempt failed, then the user-confirmed hosted DEV database was used. Runtime evidence is summarized in [UI_AUDIT.md](UI_AUDIT.md) and stored under the ignored `docs/qa/ui-audit/` directory.

## Home composition and content flow

`src/app/(public)/page.tsx` calls `getPublicHomeData()`, then renders `Header`, `HomeSections`, `StickyCtaBar`, and `Footer`. `LegacyHashRedirect` is also included. `getPublicHomeData()` concurrently queries Settings, experiences, accommodation, packages, activities, menu, gallery, stories and active reward rule through `src/server/services/public-content.ts`.

The declared `homeSectionOrder` is `hero → location → experiences-grid → why-chawan → packages → accommodation → food → activities → gallery → rewards-teaser → final-cta`. Actual render behavior is determined by the switch in `HomeSections.tsx`:

| Actual order | Rendered content | Reader / source | Empty behavior |
|---|---|---|---|
| 1 | Hero | Settings `home.hero` headline, subhead, CTA and media; address and phones from Settings; fallback metadata/copy in component/settings reader. CTA routes to `/book`; secondary to `/experiences`. | Hero always renders. Missing image leaves a forest background. Address/phone strip is conditional. |
| 1a | Owner feature, directly after hero | Settings `owner` display/name/caption/media | Hidden unless both `display` and owner media are present. |
| 2 | Location | Fixed fallback address copy in `HomeSections`; address/phones/map coordinates in `WhereWeAre.tsx`; optional map media is not passed by current Home caller. | Always renders; fallback abstract map tile. Heading and description currently repeat the same address. |
| 3 | “Stories from the farm” cards (declared `experiences-grid`) | `getPublicStories()` (`Post` + public, consented media); first three items | Hidden when no stories. This slot does not use the fetched Experiences collection. |
| 4 | “The farm experience” / Why section | Fixed heading/body fallbacks plus hard-coded `approvedFeatureLabels` in `NatureFeature.tsx`; gallery image records for mosaic | Heading and long activities/facilities list always render. Mosaic hidden unless at least three public image records and a Cloudinary name exist. |
| 5 | Stay cards (declared `packages`) | `getPublicPackages()` with valid active rates and package hero media; `mapStayPackages()` | Heading and “No published packages…” still render when empty; “View all packages” remains. |
| 6 | Accommodation cards | `getPublicAccommodations()` plus hero/gallery media; first two | Heading and empty-state copy render when empty; “View all accommodation” remains. |
| 7 | Food categories | `getPublicFood()` menu categories/items; first two, rendered as open `<details>` | Heading and empty state render when empty; “View all food” remains. |
| 8 | Activity tiles | `getPublicActivities()` and hero media; first four | Heading and empty state render when empty; “View all activities” remains. |
| 9 | Gallery | Gallery data is fetched, and `gallery` is in `homeSectionOrder`, but the switch has no `gallery` case. `HomeGallery` is not called here. | Not rendered at all by the current Home composition. |
| 10 | Rewards teaser | Active reward rule from CMS; explanatory steps and copy are hard-coded in `RewardsTeaser.tsx` | Always renders, including when no active rule exists; numeric point values are conditional on an active rule. |
| 11 | Final CTA | `final-cta` is declared and has a `FinalCta` component, but the Home switch has no `final-cta` case and does not import it. | Not rendered by current Home composition. |
| Persistent | Header, mobile CTA, footer | Header calls `getPublicSettings()` and auth session; sticky bar receives Settings phone/WhatsApp; footer reads Settings | Contact buttons conditionally disappear when settings are absent; desktop/mobile header and footer still render. |

**Composition mismatch:** the declared section order includes gallery and final CTA but neither is rendered. The `experiences` collection is fetched but not used by the Home JSX; stories occupy the experiences slot. This is confirmed by source inspection, not a browser observation.

## Motion inventory (source-level)

| Component / pattern | Trigger and values | Reduced-motion / constraints |
|---|---|---|
| `HeroHeadline`, `HeroReveal` | On client mount after line measurement/first animation frame; per-line delay 80 ms; hero eyebrow/copy delays 0/80/160 ms. CSS keyframes in `globals.css`. | Disabled for `prefers-reduced-motion` and low-power coarse-pointer devices (Save-Data, ≤4 CPU threads or ≤4 GB memory). |
| `HeroBackground` | IntersectionObserver within 120 px; passive scroll + rAF; translate Y = `(0.5 - verticalCenter / viewportHeight) × 40 × rate` (`rate=.95`, max roughly ±19 px by formula at viewport-center offsets), scaled 1.04. | Disabled for reduced motion and detected low-power coarse-pointer devices. Exact on-device rate not measured. |
| `NatureFeature` mosaic | CSS `nature-mosaic-in`, 550 ms standard easing; 80 ms stagger; card image hover scales 1.03 over 280 ms. | Global reduced-motion block removes animation; hover transform is reset under motion-reduce. |
| Stay cards | CSS `stay-card-in`, index-derived 80 ms stagger; card lift on hover/focus; images scale 1.03. | CSS global reduced-motion rules; hover scale reset on images. |
| Experience cards/carousel | CSS slide reveal with 80 ms stagger, image scale 1.03 on hover/focus; horizontal snap carousel with button smooth-scroll, keyboard, pointer/touch/wheel input. | `prefers-reduced-motion` switches programmatic scrolling to `auto`; CSS global rules disable reveal. Not used on Home currently. |
| `Reveal` / `RevealMotion` | Lazy client module; IntersectionObserver at 12% threshold, once; default Y 18 px, 550 ms, easing `[.22,.61,.36,1]`; optional delay/distance/duration. | Immediate visible state, zero duration and zero offset. `Reveal` has no current Home usage. |
| `ParallaxImage` / `ParallaxImageMotion` | Lazy client module; IntersectionObserver root margin 120 px; passive scroll + rAF; target Y offset `(0.5 - center / viewportHeight) × intensity` (default 18 px), 200 ms linear tween. | Zero offset under reduced motion. Component is used on design showcases, not Home. |
| Counters | `CountUp` starts on first intersection; 800 ms cubic ease-out; only when passed a numeric value. | Stays at final numeric value; does not animate under reduced motion. No Home stats section is mounted. |
| CSS interaction transitions | Nav underline/colour, buttons, image-card zoom, focus/hover transforms. Durations range 150–700 ms via tokens and utility classes; multiple one-off values also exist. | Some components use `motion-reduce`; global CSS disables named entrance animations. Browser behavior not measured. |
| Route transitions | No route-transition component or View Transition implementation found in inspected app sources. | Not applicable. |

There are eight named CSS entrance keyframes in `globals.css` (`nav-drop-in`, `hero-line-in`, `hero-copy-in`, `experience-slide-in`, `nature-mosaic-in`, `stay-card-in`, `guest-story-in`, `closing-cta-drift`) plus Motion-powered reveals/parallax and utility transitions. On captured Home desktop, five names executed: `hero-line-in`, `hero-copy-in`, `bounce`, `nature-mosaic-in`, and `stay-card-in`. No continuous Home parallax was observed; the Home hero media was absent, so the parallax background was not active. Mobile touch presentation was static. See `metrics.json` for scroll-step transforms and Lighthouse JSON for route measurements. A reduced-motion runtime pass was not performed.

## Design foundations

Tokens in `src/styles/tokens.css`: forest/leaf/paddy/laterite/turmeric/cream/clay/ink/mist/night palette; section spacing 48/72/112 px; fluid display/body sizes; `--motion-ease-standard: cubic-bezier(.22,.61,.36,1)`; durations 180/280/550/700/800 ms; card/panel/pill radii and text-image overlays. Fonts in `src/config/fonts.ts`: Fraunces, Inter and Noto Sans Devanagari via `next/font/google`, `display: swap`, latin subsets except Devanagari font also includes Devanagari.

Next.js installed version: 16.3.8. Its local App Router layout/page, navigation, data fetching and fonts guides were consulted before this analysis. No application code was written.
